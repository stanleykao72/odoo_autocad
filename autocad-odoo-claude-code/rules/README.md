# Rules 系統

## 概述

Rules 是**永遠生效**的開發規則，不依賴觸發關鍵字。所有代理在執行任務時都必須遵守。

## 規則列表

| 規則 | 說明 | 優先級 |
|------|------|--------|
| `security.md` | 安全規範：秘密管理、COM 安全、API 安全 | CRITICAL |
| `coding-style.md` | 編碼風格：命名規範、檔案組織、程式碼品質 | HIGH |
| `testing.md` | 測試規範：TDD 流程、覆蓋率目標、測試組織 | HIGH |
| `git-workflow.md` | Git 規範：commit 格式、分支策略、安全操作 | HIGH |
| `wpf-patterns.md` | WPF 規範：MVVM、XAML、導航、資源管理 | MEDIUM |
| `odoo-patterns.md` | Odoo 規範：API 整合、資料同步、錯誤處理 | MEDIUM |
| `agents.md` | 代理規範：調度規則、交接協議、協作模式 | MEDIUM |

## 優先級分類

| 等級 | 說明 | 處理時機 |
|------|------|---------|
| **CRITICAL** | 安全問題，可能導致資料外洩或系統損害 | 立即修復 |
| **HIGH** | 功能影響，可能導致缺陷或維護困難 | 提交前修復 |
| **MEDIUM** | 品質問題，影響可讀性或一致性 | 應該處理 |
| **LOW** | 建議改善，非強制性 | 視情況處理 |

## 新增規則

1. 在 `rules/` 下建立 `.md` 檔案
2. 使用以下結構：

```markdown
# 規則名稱

## 規則摘要
簡要說明規則目的。

## 規則內容
### 正確做法
```code
示範正確用法
```

### 錯誤做法
```code
示範錯誤用法
```

## 違反後果
說明違反此規則的影響。
```

3. 在本 README 中更新規則列表
4. 在根 CLAUDE.md 中加入參考
