## 📋 執行摘要

### 產品重新定位
MCP Server v6.0 是專為 **CAD Designer** 設計的 **AI 輔助繪圖系統**，透過 Gemini CLI 提供自然語言操作 AutoCAD 的能力。核心價值是讓 CAD Designer 從手動繪圖轉向 AI 輔助繪圖，大幅縮短設計到加工圖的工作時間。

### 核心價值主張 (重新定義)
1. **AI 優先** - 透過自然語言指令操作 AutoCAD，告別繁瑣的手動操作
2. **配置智能管理** - AI 理解並協助管理 AutoCAD 配置 (Layout)，每張加工圖都能智能化處理
3. **個人化適應** - AI 學習每個 CAD Designer 的工作習慣，提供客製化體驗
4. **零學習成本** - 適應現有工作流程，無需改變習慣
5. **漸進式智能** - 使用越久，AI 助手越聰明

### 關鍵成功指標 (重新聚焦)
- **操作時間縮短**: 基本繪圖從 30秒 → 5秒 (83% ↓)
- **配置管理效率**: 完整加工圖集從 2小時 → 15分鐘 (87% ↓)
- **學習曲線**: 新 Designer 上手時間從 1週 → 1天 (85% ↓)
- **工作滿意度**: CAD Designer 工作滿意度提升 80%
- **AI 適應性**: 個人化建議準確率 > 90%

## 🎯 產品目標與策略 (重新定義)

### 核心目標 (What)
1. **讓 CAD Designer 用說的就能畫圖** - 自然語言繪圖指令
2. **智能配置管理** - AI 協助管理 AutoCAD 配置和加工圖
3. **個人化工作體驗** - 適應每個 Designer 的獨特工作風格
4. **保持工作自主權** - AI 建議但 Designer 決定

### 戰略背景 (Why)
**市場機會**:
- CAD 工作仍然高度依賴手動操作，效率提升空間巨大
- AI 技術成熟，可以理解自然語言並執行 CAD 操作
- 現有 CAD 工具缺乏智能化配置管理
- 個人化 AI 助手將成為專業工具的標準配置

**用戶痛點**:
- 重複性的手動繪圖操作耗時費力
- 配置管理繁瑣，容易出錯
- 學習複雜的 CAD 指令需要大量時間
- 每個 Designer 工作習慣不同，現有工具無法適應

**技術優勢**:
- MCP 協議提供標準化的 AI-CAD 整合介面
- Gemini CLI 具備強大的自然語言理解能力
- AutoCAD COM 介面支援程式化操作
- 可選的 Odoo 整合為未來業務流程擴展預留空間

### 目標用戶 (Who)
**主要用戶**: 公司內部 CAD Designer
- 機械設計工程師
- 建築設計師
- 製造業繪圖員
- 工程顧問公司設計師

**用戶特徵**:
- 熟悉 AutoCAD 操作
- 需要高效率完成設計到加工圖的工作
- 每人有獨特的工作習慣和偏好
- 希望減少重複性手動操作
- 對新技術持開放態度但不想改變既有流程

## 🚀 產品功能規格 (重新聚焦)

### 核心功能領域

#### 1. AI 輔助 AutoCAD 繪圖
**功能描述**: 透過自然語言指令快速執行 AutoCAD 繪圖操作

**關鍵特性**:
- **基礎繪圖指令**: "畫一個直徑 50 的圓形"、"從這裡到那裡畫一條線"
- **智能參數推斷**: AI 根據上下文推斷合理的參數值
- **批次操作支援**: "將所有圓形移動到新圖層"
- **錯誤理解與修正**: AI 能理解模糊指令並主動詢問細節

**用戶價值**:
- 說話就能畫圖，解放雙手
- 大幅縮短重複性操作時間
- 降低 CAD 指令學習門檻

#### 2. 智能配置管理系統
**功能描述**: AI 協助管理 AutoCAD 配置，智能化加工圖創建流程

**關鍵特性**:
- **配置建議系統**: AI 分析零件複雜度，建議適合的視圖和配置
- **靈活命名支援**: 支援任意的配置命名方式，不強制標準
- **跨配置一致性**: 自動檢查並保持不同配置間的設計一致性
- **出圖準備輔助**: AI 協助準備完整的工程圖集

**用戶價值**:
- 配置管理從繁瑣變智能
- 確保加工圖的專業品質
- 支援個人化的組織方式

#### 3. 個人化學習引擎
**功能描述**: AI 學習並適應每個 CAD Designer 的工作習慣

**關鍵特性**:
- **偏好學習**: 記住常用的參數、比例、命名方式
- **工作模式識別**: 理解不同 Designer 的工作風格
- **個人化建議**: 基於歷史行為提供客製化建議
- **跨會話記憶**: 長期記住個人偏好和工作習慣

**用戶價值**:
- 越用越符合個人習慣
- 無需強制改變既有工作方式
- 提供專屬的 AI 助手體驗

#### 4. 彈性 Odoo 整合
**功能描述**: 可選的 Odoo 認證和資料同步

**關鍵特性**:
- **簡單認證**: 透過 Odoo 帳號登入系統
- **可選同步**: Designer 自主決定是否同步配置資訊
- **版本追蹤**: 選擇性的工程圖版本管理
- **未來擴展**: 為更深度的 BOM 整合預留介面

**用戶價值**:
- 不強制使用，完全可選
- 為未來業務流程整合保持彈性
- 支援團隊協作需求

## 👥 用戶故事與使用場景 (重新聚焦)

### 核心使用場景

#### 場景 1: 日常繪圖工作
**情境**: CAD Designer 小王需要繪製一個機械零件

**AI 輔助流程**:
1. **自然語言繪圖**:
   - 小王: "畫一個直徑 80 的法蘭"
   - AI: "好的，創建直徑 80mm 的圓形法蘭，需要加螺絲孔嗎？"
   - 小王: "8 個 M10 螺絲孔，均勻分布"
   - AI: 立即執行，並問 "需要標註尺寸嗎？"

2. **智能配置建議**:
   - AI: "這個零件建議創建主視圖和 A-A 剖面圖配置，需要嗎？"
   - 小王: "好，還要加個等角視圖"
   - AI: 自動創建三個配置，使用小王慣用的命名方式

**期望結果**: 完整零件繪制從 1 小時縮短到 15 分鐘

#### 場景 2: 配置管理工作
**情境**: CAD Designer 小李需要為複雜組件準備完整加工圖集

**AI 輔助流程**:
1. **批次配置操作**:
   - 小李: "為這個組件創建完整的工程圖集"
   - AI: "分析組件複雜度...建議創建：主視圖、俯視圖、左視圖、A-A剖面圖、B-B剖面圖、爆炸圖。使用你常用的 1:2 比例嗎？"

2. **個人化工作流**:
   - AI 記住小李喜歡的配置順序和命名規則
   - 自動套用小李慣用的圖框格式
   - 提醒小李常忘記的標註事項

**期望結果**: 完整圖集準備從 4 小時縮短到 30 分鐘

#### 場景 3: 新手 Designer 學習
**情境**: 新進 CAD Designer 小陳剛開始使用系統

**AI 適應流程**:
1. **漸進式學習**:
   - 小陳: "我想畫個齒輪，但不確定參數"
   - AI: "沒問題！齒輪需要這些參數：模數、齒數、壓力角。我來一步步引導你。"

2. **習慣建立**:
   - AI 觀察小陳的操作偏好
   - 逐漸記住小陳的工作習慣
   - 提供越來越精準的個人化建議

**期望結果**: 新手上手時間從 2 週縮短到 3 天

## ⚠️ 關鍵技術約束

### COM 連線管理約束
**關鍵限制**: GUI 與 MCP Server 必須避免重複 COM 連線

#### 技術需求
- ✅ **單一 COM 連線原則**: 只能有一個 AutoCAD COM 連線實例
- ✅ **共享實例機制**: MCP Server 必須使用 GUI 建立的共享連線
- ✅ **連線生命週期**: GUI 優先建立，MCP Server 接收共享實例
- ✅ **狀態同步**: 操作後狀態必須在 GUI 和 MCP 間同步

#### 風險緩解
- ❌ **衝突檢測**: 自動檢測重複 COM 連線並告警
- ❌ **自動修復**: 檢測到衝突時自動關閉重複連線
- ❌ **監控機制**: 持續監控 COM 連線健康狀態
- ❌ **容錯處理**: 連線異常時的恢復機制

#### 實作約束
```yaml
COM_CONNECTION_RULES:
  - GUI 必須先建立 AutoCAD 連線
  - MCP Server 禁止創建獨立 COM 連線
  - 所有 AutoCAD 操作通過共享實例執行
  - 狀態變更必須同步到所有使用者
```

#### 測試需求
- **P0**: COM 衝突檢測測試
- **P0**: 共享實例功能測試  
- **P1**: 同時操作壓力測試
- **P1**: 狀態一致性驗證測試
